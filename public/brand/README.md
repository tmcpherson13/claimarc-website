# ClaimARC brand assets

Optimized PNGs used by the site (transparent, tightly cropped from the official
logo package). Source vector: `claimarc-logo-source.pdf` (the original `.ai` is
in the brand package, not committed here).

| File | Use |
| --- | --- |
| `claimarc-horiz-white.png` | Header / footer on dark navy backgrounds |
| `claimarc-horiz-color.png` | Full-color lockup on light backgrounds |
| `claimarc-wordmark-*.png`  | Wordmark + tagline, no arc mark |
| `claimarc-icon-*.png`      | Arc mark only (favicon, compact spots) |
| `claimarc-stacked-color.png` | Stacked lockup |

Brand colors (sampled from the logo):
- Navy `#00457E` · Cyan `#00A0C8` · Green `#68B840`

Rendered via `src/components/Logo.tsx`.
